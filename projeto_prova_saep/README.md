# 📦 Gerenciador de Almoxarifado - Projeto SAEP

Esta pasta contém o desenvolvimento de um sistema para gestão de estoque e almoxarifado, focado em rastreabilidade, controle de níveis críticos e transparência de processos. O projeto foi estruturado para atender aos requisitos técnicos de avaliação do SAEP.

---

## 🚀 O Desafio
Desenvolver uma solução que permita ao usuário do almoxarifado cadastrar produtos e gerenciar de forma intuitiva a entrada e saída de itens. O foco principal é a automação do controle de estoque e a garantia da transparência através de registros detalhados.

---

## 💡 Funcionalidades Principais

* **Gestão de Inventário**: Cadastro e visualização de produtos de forma intuitiva.
* **Alertas de Estoque Mínimo**: Mecanismo automático que emite notificações quando o nível de qualquer produto atinge o limite configurado.
* **Histórico de Movimentações**: Registro completo de cada entrada e saída (Log de Operações).
* **Rastreabilidade**: Identificação obrigatória do responsável e da data/hora de cada operação.
* **Controle de Acesso**: Sistema de login para garantir a segurança dos dados e responsabilidade nas ações.

---
