# 📚 Projetos Diversos

> **⚠️ Observação:** A maioria dos projetos desta pasta não estão responsivos para smartphones, pois foram desenvolvidos no primeiro semestre do curso, quando o foco estava em fundamentos básicos.

Esta pasta reúne exercícios técnicos, componentes de interface e lógicas fundamentais desenvolvidos durante a formação no SENAI. O foco aqui é demonstrar a versatilidade na aplicação de tecnologias web em diferentes contextos e desafios de programação.

---

## 🛠️ Portfólio de Estudos e Componentes

### 💼 Aplicações de Negócio & E-commerce
* **Resenha em Campo (microempresa)**: Loja virtual de artigos esportivos com catálogo completo e navegação estruturada entre múltiplas páginas.
* **AppleHub (caixa)**: Sistema de checkout com lógica para seleção de iPhones, cálculo de subtotal e aplicação de 10% de desconto.
* **Controle Financeiro**: Ferramenta prática para monitoramento de fluxo de caixa (entradas e saídas).
* **Cafeteria**: Landing page institucionais focada em design de interface para serviços.

### 🎮 Jogos e Experiências Interativas
* **emulaHub**: Central de jogos clássicos com interface moderna, apresentando um carrossel dinâmico de destaques e navegação por cards categorizados para emuladores e consoles como GBA, 3DS e PS2.
* **Jukebox**: Player de áudio funcional com sistema de troca de faixas e controles de reprodução.
* **Pedra-Papel-Tesoura**: Jogo clássico explorando lógica de randomização e condições de vitória em JavaScript.
* **RetroPlay**: Interface temática inspirada em consoles clássicos com foco em estilização personalizada.
* **Ecociclo**: Projeto focado em sustentabilidade com interface visual para conscientização ambiental.

### 🖼️ Componentes Visuais e Interatividade (DOM)
* **Contagem Regressiva (contagem)**: Countdown dinâmico onde o usuário define uma data alvo; apresenta uma **barra de progresso** e dispara um GIF de conclusão ao finalizar.
* **Cartão Interativo (cartao-comemorativo)**: Componente com animação CSS *flip*, simulando a rotação física de um cartão para revelar o verso ao clique.
* **Slides**: Carrossel de imagens dinâmico para exibição de conteúdo sequencial.
* **Formulário**: Sistema de cadastro estruturado para prática de coleta e validação de dados.
