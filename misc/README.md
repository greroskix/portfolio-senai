# 📚 Fundamentos e Exercícios Técnicos (Misc)

Esta pasta reúne o alicerce técnico desenvolvido durante a formação no SENAI. O conteúdo abrange desde a lógica de programação pura e modelagem de dados até a transição para interfaces dinâmicas com manipulação de DOM.

---

## 🛠️ Portfólio de Estudos e Lógica

### 🧠 algoritmo
Exercícios focados em estruturar o pensamento lógico e resolver problemas complexos:
* **Atividades Visual G**: Primeiros contatos com lógica de programação via pseudocódigo.
* **Enquanto Repita**: Práticas com estruturas de repetição para controle de fluxo.
* **Listas de Estruturas**: Exercícios focados em tomada de decisão e fluxo de controle.
* **Lista de Vetores e Matrizes**: Implementação e manipulação de listas de dados multidimensionais.

### 🗄️ banco-de-dados
Projetos de modelagem e persistência de dados:
* **Modelagem Conceitual**: Diagramas (PNG) para contextos de Curso, Empréstimo, Esporte e Hotel.
* **Atividades Práticas**: Modelagem estruturada para sistemas de Empresa e Loja.

### 📊 fluxogramas
Representação visual de algoritmos e arquitetura de sistemas em formato PDF:
* **Exercícios**: Sequência de fluxogramas (Ex1 ao Ex10) detalhando resoluções lógicas.

### 🌐 listas-de-exercicio
Evolução do aprendizado em JavaScript, partindo da lógica de console até a criação de componentes interativos no navegador:
* **Lógica de Script (list1.js a list11.js)**: Exercícios fundamentais de processamento de dados via console.
* **Manipulação de DOM (list12 a list16)**: Integração entre HTML e JS para capturar dados de input e exibir resultados dinamicamente na tela.
* **Interatividade Prática**: Criação de sistemas de soma, concatenação de nomes e verificadores de idade com interfaces visuais.
