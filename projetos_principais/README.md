# 💻 Projetos Principais

Esta pasta reúne as aplicações desenvolvidas com foco em interfaces interativas, manipulação de eventos e lógica de programação. Cada subpasta contém um projeto independente pronto para ser explorado.

---

## 🚀 Lista de Projetos

### 👻 GhostHunt (Caça Fantasma)
Um jogo de agilidade e reflexos rápidos contra o tempo.
* **Mecânica:** O jogador tem 15 segundos para capturar o maior número de fantasmas.
* **Diferencial:** Fantasmas coloridos garantem uma pontuação maior.
* **Tecnologias:** HTML5, CSS3 e JavaScript.

### 🔑 Gerador de Senhas
Ferramenta para criação de senhas fortes e seguras.
* **Tecnologias:** JavaScript, Node.js, HTML5 e CSS3.

### 🧠 Memorix
Jogo da memória completo com foco em experiência do usuário.
* **Tecnologias:** HTML5, CSS3 e JavaScript.

### 🎲 Dungeons & SENAI
Um jogo de RPG interativo baseado em texto e escolhas narrativas.
* **Tecnologias:** HTML5 e CSS3.

### 📝 Termo
Clone do jogo de adivinhação de palavras, focado em lógica algorítmica.
* **Tecnologias:** HTML5, CSS3 e JavaScript.

---

## 🛠️ Como rodar os projetos?

1.  Clone o repositório.
2.  Navegue até a pasta do projeto desejado.
3.  Abra o arquivo `index.html` em qualquer navegador moderno.
