## 📂 Estrutura do Repositório

O projeto está organizado para refletir a evolução do aprendizado, separando exercícios de lógica de aplicações completas:
* **`📂 assets/`**: Pasta com os arquivos style.css e script.js do arquivo index principal.
* **`📂 misc/`**: Base técnica, fundamentos e exercícios de lógica.
* **`📂 projeto_prova_saep/`**: Sistema de Gestão de Almoxarifado desenvolvido para avaliação técnica.
* **`📂 projetos_principais/`**: Aplicações com interface gráfica (UI), arquivos de estilo e interatividade dinâmica.

## 🏆 Projeto de Avaliação (SAEP)

Projeto desenvolvido para a avaliação prática do SAEP.
